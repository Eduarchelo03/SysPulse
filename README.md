# SysPulse

SysPulse is a lightweight Linux system monitoring tool written in C.

The goal of the project is to retrieve and display system information directly from Linux interfaces such as `/proc` and `/sys`.

## Planned features

- Hostname
- Kernel information
- CPU information
- Memory usage
- System uptime
- CPU temperature
- Disk usage
- Network information

## Technologies

- C
- Linux
- GCC
- Git
